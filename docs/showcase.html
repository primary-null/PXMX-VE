Jump to scenes ↓ User guide
01Cluster home & guest detail
Cluster home lays out every guest, node, and storage pool on one screen. Tap any guest card and you get its detail page.
  • Guest cards show CPU, memory, disk, and uptime
  • Tabs switch between guests, nodes, and storage; the latest log line stays pinned at the bottom
  • Detail page: start, stop, reboot, suspend; auto-start on boot
  • Console, hardware, and network tabs
02Guest console
Fullscreen console, straight from the guest detail page. Turn the phone sideways and the terminal takes the whole screen.
  • Works for VMs and containers
  • Session menu: resize, reconnect, disconnect
03Deploy from template
Clone a template into a new VM without a desktop. The dialog suggests the next free VMID and a name, and errors show right where they happen.
  • Template picker across the whole cluster
  • Suggested VMID and name, edit in place
  • New VM lands on the cluster ready to start
  • Errors stay visible in the dialog
04Tasks & updates
Two views of work on the cluster: the task log, and a package upgrade mid-run.
  • Backups and updates finish with OK statuses
  • Each task shows its user and start time
  • Updates walk through fetch, install, and cleanup with live progress
05Appearance
OLED dark is the default. Light and follow-system are built in, and theme and accent color are set per profile.
  • Three theme modes: OLED dark, light, follow system
  • OLED dark turns unlit pixels fully off
  • Accent color picker
06Storage & nodes
Usage as fills: green, amber, red at a glance. Storage per pool, memory per node.
  • Each pool shows used and total, with a fill to match
  • Node cards show memory, CPU, and what's running on them
  • Tapping a row opens the detail page
07All servers
Every saved host probed at once: online state, version, what's running.
  • Hosts light up green or drop off the list
  • Real version string per host, not a guess
  • Something else answering on the port stays separate and labeled
08No server handy
The login screen has a demo entry. Tap it and the app opens with a sample cluster loaded, no connection needed.
Demo mode — for people who just want to look at the app without connecting it to anything. Everything in it behaves like a real cluster, nothing is saved, and your own server stays behind the profile menu.
